# Componentes redistribuídos

- JavaFX 21.0.9: OpenJDK/OpenJFX, GPL v2 com Classpath Exception. Textos preservados
  do repositório https://github.com/openjdk/jfx21u/tree/21.0.9%2B1.
  Incluem os avisos JPEG e Mesa dos módulos utilizados (base, graphics, controls).
- Gson 2.11.0: Apache License 2.0, texto de
  https://github.com/google/gson/blob/gson-parent-2.11.0/LICENSE.
- Runtime Java: as distribuições oficiais desta prévia usam Eclipse Temurin 21,
  gerado pelo jpackage dos runners. Os avisos do runtime são mantidos em sua pasta
  `legal`. Código-fonte e distribuição: https://adoptium.net/temurin/releases/.

Os fontes do jogo estão em https://github.com/luigigiarola-dev/SuperRpgTerminal.
Builds locais incluem o runtime do JDK usado para gerá-los; não devem ser publicados
como se fossem os pacotes oficiais gerados com Temurin.
